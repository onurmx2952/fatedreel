# O13 design and verification

The existing O11 paper/forest/editorial-serif identity continues in a separate story reader. Primary task: choose an A1/A2 everyday story, read/listen, touch an unfamiliar word, save it with its sentence, then recall it later. Library filters, story player and three-question comprehension flow use short Turkish labels. No new account is required.

Six MIT illustrations from the pinned English Trainer source provide context rather than decoration. Motion is limited to 320ms section arrival, 200ms dialog/feedback arrival and button press feedback; prefers-reduced-motion removes it.

Browser verification: saved vocabulary, hidden-answer guard, self-rating, reload persistence and question feedback checked in IAB, including the 390px mobile navigation. Console had no JavaScript errors. Screenshot capture failed in both IAB screenshot APIs; Chrome/native surfaces were unavailable. An isolated oil-ui reviewer was requested but had no browser inventory either. Consequently no visual screenshot score is claimed. Automated model, content, audio and service-worker tests supplement the interaction checks.
