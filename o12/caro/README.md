# Caro Davy recordings

240 static clips generated with the same Kyutai Pocket TTS `caro_davy` preset used for /o11. Coverage: first 60 A1 words, first 60 A2 words and each word's first English example in the deployed Atlas order. The source English text remains the Word Atlas content credited by the application. index.json maps normalized text to a clip URL. Other words retain their original recorded pronunciation; this directory is not a complete replacement of the Atlas audio library.

Engine: https://github.com/kyutai-labs/pocket-tts
Voice catalog: https://huggingface.co/kyutai/tts-voices
