# Web doğrulaması

Pyodide Python 3.14.2 ve Mesa 3.5.1 ile tarayıcıda 100 x 240 aylık seri yeniden çalıştırıldı. İndirilen JSON içinde 24100 aylık kayıt ve 100 sonuç doğrulandı. Native Python sonuçlarıyla rejim sınıfları ve olaylar eşit; tüm sayısal aylık kayıtlar 1e-12 mutlak toleransla eşit. Grafik oynatması, deney seçimi ve JSON indirmesi tarayıcıda doğrulandı. Model/dışa aktarım testleri: 16 geçti.
